# ScrubChipRow alternate lit state

A `ScrubChipRow` item's lit state is only true or false. The chip has a
third look (`data-lit="alt"`), but the row cannot use it, so a pick made
through `onAltSelect` (right button) looks the same as a normal pick.

- [ ] Items can be lit `'alt'`.
- [ ] A story shows `onAltSelect` with the alternate look.

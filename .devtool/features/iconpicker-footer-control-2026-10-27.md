# IconPicker footer control

`IconPicker` takes a `footer`, but phosphor ships no control for it.
The Footer story styles plain buttons with the internal
`chrome-iconpicker-cell` class; phosphor-dials does the same for its
mode segment (`.pd-mode-segment`).

- [ ] A public footer control (a segmented row of picker cells).
- [ ] The Footer story and phosphor-dials use it instead of the internal class.
